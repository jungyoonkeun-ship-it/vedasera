VEDA SERA HEADER LOGO FIX

This package ONLY changes the header logo size.
It does not replace any images, HTML content, or sections.

Recommended application:
1. Open your current style.css in GitHub.
2. Copy the entire contents of header-logo-fix.css.
3. Paste it at the VERY END of style.css.
4. Commit changes.
5. Hard refresh vedasera.com.

Result:
- Desktop header logo: 220px wide
- Mobile header logo: 180px wide
- Logo aspect ratio preserved
- Header height adjusted so the logo does not get clipped

Do NOT replace your existing style.css with this file.
